# Sina Signature

Premium personal resume / portfolio for **Sina Rostamabadi**.

## Run

```bash
cd sina-signature
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Features

- EN / FA / TR
- Light / dark theme
- Hero with contact strip
- Selected work, experience, skills, about, contact
- Framer Motion reveals + scroll progress

Built with Next.js 16, Tailwind CSS 4, Framer Motion.
